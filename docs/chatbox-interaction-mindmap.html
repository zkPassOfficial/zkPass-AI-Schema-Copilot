zkPass Schema Copilot
Deep Agents Architecture Flow

Supervisor orchestrator + specialized Subagents + Planning/Todos + Human-in-the-Loop gates + Scratchpad context. The Supervisor looks up reusable endpoint knowledge, builds a plan, delegates to subagents sequentially, and pauses at gates for human decisions. The Scratchpad (dashed purple) carries shared state between agents via chrome.storage.session.

AnalysisAgent AI Analysis
  • Build system prompt (schema rules + assertion patterns)
  • Bind lookup endpoints by host + method + path + optional query/body/header match
